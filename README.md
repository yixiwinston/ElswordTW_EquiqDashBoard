# 配裝 Dashboard

收集玩家用[配裝模擬器](https://as930010.github.io/damage-calculator/)做的配裝，整理成可排序、可分享的列表。
點任一列可以看完整的裝備與數值明細。

## 怎麼上傳

1. 在配裝模擬器配好裝備，匯出 JSON 檔（檔名不限）。
2. 打開網站右上角的「上傳我的配裝」，用 Discord 登入。
3. 填遊戲內角色名稱（可加備註，例如「過渡中」），選擇剛剛匯出的檔案，送出。
4. 通過自動檢查後，幾分鐘內就會出現在列表上。上傳頁的「我的配裝」會顯示每一份的狀態；沒通過時也會顯示原因。

- 每個 Discord 帳號最多保留 5 份配裝（不同角色，或同一角色用不同備註）。
- 用**相同的角色名稱與備註**再上傳一次，就是更新那一份。
- 要移除某一份，在「我的配裝」按「刪除」。
- 每份配裝有固定網址，可以直接分享。

## 會公開哪些資料

上傳即表示你同意公開以下資料：

- **Discord 使用者名稱與頭像**：在登入當下取得，無法自填，所以別人無法冒用你的名字。頭像網址裡含有你的 Discord 數字 ID。
- **遊戲內角色名稱與備註**：你在上傳時填寫的內容。
- **配裝內容**：匯出檔的完整內容，以及據此算出的數值。

這些資料會出現在網站上，也會以檔案形式存放在這個公開的 GitHub repo 裡。
**請注意：刪除或更新後，網站上不會再顯示舊資料，但舊版本仍會留在 repo 的歷史紀錄中。**
改名或換頭像後，要重新上傳才會更新。超過 180 天沒有更新的配裝不會再列出。

## 數值怎麼來的

- **列表上的數字不是取自你上傳的檔案**，而是由配裝模擬器的程式重新計算，所以修改檔案內的數字無法灌分。
- **總增幅**：純面板能提供的傷害，不帶入任何外部 Buff／Debuff。檔案內自帶的開關（藥水、襲擊戰等）照檔案內容計算。
- **致命一擊、極大化**：這兩項有遞減，預設顯示副本內的實際機率；點一下可切換成黃字總和。
- **賦靈錄、聖獸精靈石顏色**：直接取自上傳的檔案。
- **排序**：可依 Discord 名稱、遊戲內角色名稱、職業、總增幅排序。

配裝是玩家自己填的，網站只能保證「數字確實由這份配裝算出」，無法保證玩家真的擁有這些裝備。

## 防濫用

上傳需要 Discord 登入，帳號必須註冊滿一段時間；每人與全站都有送出頻率上限；每份檔案都會經過格式檢查與實際計算，不合格會被退回。
發現濫用的帳號可以停權。
